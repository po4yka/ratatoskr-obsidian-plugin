# Ratatoskr Obsidian Plugin

The Obsidian plugin of the Ratatoskr `plugin` channel. It sends the file changes of a vault that
does not use Obsidian Sync to Ratatoskr, through Edge.

The implementation is in progress. See `openspec/changes/obs-023-obsidian-plugin/tasks.md` for the
tasks that are done.
